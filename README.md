# 🤖 Customer Support Chatbot

> A full-stack customer support chatbot built with React and Node.js, featuring real-time automated responses, conversation history, and a clean responsive UI.

## ✨ Features
- 💬 Real-time automated chat responses
- 📜 Conversation history tracking
- 🔍 Keyword-based response matching
- 📱 Fully responsive across desktop, tablet, and mobile
- ⚡ Fast and lightweight React frontend
- 🎨 Clean, modern chat UI

---

## 🎯 What This Project Demonstrates
- **Frontend Development** — React component architecture with hooks and state management
- **UI/UX Design** — Clean chat interface with smooth user interactions
- **API Integration** — RESTful API communication between frontend and backend
- **QA Mindset** — Built with testability in mind from the start
- **Deployment** — Hosted on GitHub Pages with automated deployment

---

## 🧪 Testing Approach
- **Manual Testing** — Test case design covering happy path and edge cases
- **UI Automation** — Playwright scripts for automated regression testing
- **API Testing** — Postman collections for endpoint validation
- **Negative Testing** — Empty input, long messages, special characters

```bash
cd customer-support-chatbot
npm install
npm run dev
```
